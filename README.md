# Kalei

Demo shop for the fictional artist Kalei Solano. Originals and prints are listed with USD prices. Every order goes to WhatsApp. There is no cart and no checkout.

Live site: https://mohammedbagowabair.github.io/Kalei-Color-Art-Shop-Website/

Demo prices for illustration only. Kalei Solano is not a real artist. The pictures are stock photographs from Unsplash and Pexels, credited in the page footer.

Display type is Rowdies and the text face is Sora, both under the SIL Open Font License.
